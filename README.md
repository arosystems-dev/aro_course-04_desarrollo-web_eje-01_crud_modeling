# CRUD DE ARTICULOS

Diseño y modelado del proyecto **CRUD de Artículos**, desarrollado mediante **Enterprise Architect**.

### ESPECIFICACIÓN TÉCNICA

**Herramienta:** Enterprise Architect  
**Lenguaje de modelado:** UML

### ARCHIVO DE DISEÑO

Para acceder al diseño del proyecto, descargar y abrir:

**`crud_modeling.EAP`**

El archivo contiene los modelos y diagramas UML utilizados para el diseño del sistema.
