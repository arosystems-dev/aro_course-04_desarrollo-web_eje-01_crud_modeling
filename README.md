# CRUD DE ARTÍCULOS

Diseño y modelado del proyecto **CRUD de Artículos**, desarrollado mediante **Enterprise Architect**.

### ESPECIFICACIÓN TÉCNICA

**Herramienta:** Enterprise Architect  
**Lenguaje de modelado:** UML

### ARCHIVO DE DISEÑO

Para acceder al diseño del proyecto, descargar y abrir el siguiente archivo:

**`crud_modeling.EAP`**

El archivo contiene los modelos y diagramas UML correspondientes al diseño del sistema.
